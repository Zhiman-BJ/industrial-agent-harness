# Agent instructions

See [AGENTS.md](AGENTS.md) for the repository instructions. This file is an entry point for tools that look for `AGENT.md`.

When adding or extending a Viewer, follow the [Viewer integration contract](AGENTS.md#viewer-integration-contract): shared zoom/Fit, wheel/pinch, fullscreen with state retention, read-only boundaries, and real-path verification. Update the repository-root [Viewer list](README.md#已接入的-viewer) in the same change with supported inputs, features, dependencies, and limitations.
