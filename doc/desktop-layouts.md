# 自适应窗口与标签页工作台

2026-10-08；2026-10-16 补充统一顶栏与内容对齐。经典两列和标签页共用现有聊天、Project 文件读取、Viewer Registry 与 ViewerCanvas。此变更只涉及桌面显示与导航。

本轮已按 [PD-080](product-decisions.md#pd-080统一桌面顶栏与聊天内容边界) 调整桌面外壳，macOS arm64 本次构建的 UI、语言、并行聊天与真实 FreeCAD／OCCT 布局回归已通过。原生窗口截图与完整证据统一见[实施与验收记录](desktop-shell-layout-plan.md#实施与验收记录)。本轮未执行 Windows、Linux 或发布包验收。

## 使用

- 全局顶栏：58 px 高，横跨侧栏和工作台；窗口控制区旁的单一侧栏开关保持固定位置。聊天显示“项目名 / 当前聊天名”，项目详情、能力中心和激活文件显示各自当前位置；长标题省略但保留完整名称提示。
- 两列模式：全局顶栏的“切换为标签页布局”按钮进入标签页。现有分隔线仍支持拖动、键盘和双击复位。
- 标签页模式：全局顶栏下方固定当前聊天标签，文件和 Viewer 各占一个标签。点击全局顶栏的“切换为两列布局”恢复并排显示。
- `+` 打开当前项目文件树；单击文件复用一个临时预览标签，标题以斜体显示。双击文件／标签或点击图钉将其固定；固定文件再次单击只激活原标签。关闭文件标签只关闭查看，聊天删除仍使用原有项目导航。
- 标签栏支持左右方向键、Home、End 和 Delete。关闭当前文件后选择相邻标签，最后一个文件关闭后回到聊天。长标题省略，超出宽度的标签可横向滚动。
- 布局选择保存在本机。标签和 Viewer 会话仅保留在本窗口；重启后按原有聊天历史恢复机制打开聊天，不自动重新打开工程文件。

## 窗口与状态

首次窗口按当前主屏的可用区域居中，尺寸不超过 1440 × 900，避开任务栏或 Dock。原生最小窗口改为 640 × 480；更小的显示器以其可用区域为界。显示器移除或可用区域改变时，将窗口带回可见区域。尺寸单位为逻辑像素。

全局顶栏在 macOS 为原生红黄绿预留空间，其他平台仅显示一组自绘窗口控制按钮；能力中心不重复显示窗口控制。顶栏空白区域可拖动窗口，按钮与其他可操作内容保持可点击。侧栏宽 228 px，从顶栏下方开始，完整显示品牌名称和原有绿色标识，设置仍在导航左下角。

窗口内容宽度小于 900 时自动采用标签页，恢复宽度后重新使用用户选择的布局。小于 760 时，项目导航成为可打开的抽屉，抽屉和遮罩都从顶栏下方开始，不覆盖侧栏开关。窗口恢复到至少 760 px 时清除抽屉打开状态，再次缩窄不会自动弹出旧抽屉。自动适配不覆盖保存的布局选择。

聊天正文、远程运行状态、输入框和底部说明共享 640 px 最大宽度与水平留白，空间不足时同步缩小。消息刻度栏保留可用空间，不单独推偏正文；错误、任务清单和附件沿用原有展示。空白聊天保留原有欢迎区，输入区在聊天面板内水平对齐；已有消息时输入区保留在底部。极窄分屏中，输入区底部控件可换行，审批选择保持可读宽度，模型名称省略，发送操作仍可达。58 px 只适用于全局顶栏，不改变 Viewer 等局部工具栏的高度。

切换聊天／文件或布局时保留聊天输入、附件、滚动位置和已打开 Viewer 的相机、选择、搜索等状态。收起／展开侧栏保留同一 textarea、草稿、附件和 Viewer；长消息重新换行时保留阅读锚点。Viewer 全屏仍使用原工作区根节点，缩放、Fit、退出按钮与 Esc 保持可用，退出恢复布局与同一 Viewer。后台任务继续使用原有 Kimi 2.1.1 生命周期；聊天标签显示运行、等待审批或等待回答提示，切回聊天处理。隐藏工作区也保留文件查看会话；关闭文件或更换项目释放对应 Viewer。文件树再次打开文件时刷新变更的内容，项目切换期间迟到的文件读取不会进入新项目。

## 验证

2026-10-16 在 macOS arm64 本次构建中通过 `test:ui`（含阅读刻度栏）、`test:language`、`test:parallel` 与 `test:cad-resize`。新增检查包括 58 px 顶栏／228 px 侧栏／640 px 内容边界、固定侧栏开关、页面上下文、草稿与阅读锚点、640 × 480 抽屉，以及 280 px 聊天分屏的中英文输入控件换行；真实 FreeCAD／OCCT 检查同一 canvas、相机、比例与全屏／Esc。构建、格式、架构、发行配置、lint、portable 和 package smoke 门禁也已通过。结果保存在 `dist/ci-reports/20261016-shell-212-2c3c2fe7`，完整计数、原生截图及验证限制见[统一验收记录](desktop-shell-layout-plan.md#实施与验收记录)。原生窗口截图确认窗控与侧栏开关无重叠，最小化／恢复已实测；鼠标窗控和顶栏拖动受电脑控制工具影响，仍待有效复核。Godot、工业内核前置与旧 Viewer 聚合入口的未通过情况也在该记录中保留。

以下为既有测试入口及覆盖说明；本轮实际执行范围以上述记录为准。

- `test:ui`：真实 Electron preload/IPC，项目创建、原始源码、Markdown 与文本 Viewer、多文件标签、聊天草稿、布局切换与保存、键盘关闭与焦点、两种主题和语言；1440 × 900、1250 × 800、1000 × 650、800 × 600 和原生 640 × 480 的可见控件、面板边界、导航与设置。
- `test:parallel`：原有并行聊天、审批／提问与停止隔离；新增文件标签隐藏聊天时等待审批的提示、恢复处理和项目切换清理。
- `test:cad-resize`：实际 FreeCAD 零件与 OCCT WebGL2 像素比例，分隔线与全屏，以及两列 → 标签 → 聊天 → 模型 → 两列。检查同一个 WebGL canvas、相机参数与模型比例。
- `test:language`、`test:documents`、`test:engineering`、`test:kicad`、`test:godot`：复用现有 Viewer 回归。多 Viewer 存在时只检查当前文件的内容；保留对源文件不变的断言。
- `test:gui-settings`：真实 preload/IPC 开启与关闭；在隔离进程模拟缺失／部分／已授予／查询失败，检查提示、自动刷新与系统设置链接，测试不更改 OS 权限。
- Desktop 单元测试模拟任务栏偏移、小显示器、负坐标副屏移除和可用区域改变。架构门禁覆盖整个 renderer，保持领域中立的 Viewer Canvas／文字接口。

2026-10-08 原始布局变更的本地运行平台为 macOS Apple Silicon。既有 CI 包含 macOS／Windows 桌面 UI 门禁和 macOS CAD 门禁；物理多显示器热插拔与其他 OS 的验收以其运行记录为准，不由本次 macOS 结果推断。

2026-10-08 的本地 UI、语言、并行聊天与桌面操作设置走真实 preload／IPC。该轮 KiCad 与实际 Godot Web Export 另外在隐藏窗口验证标签切换后的 iframe、相机、暂停场景、缩放与只读边界；两次隐藏运行省略原生全屏切换，不能作为完整全屏验收。本轮实际 CAD／OCCT 的窗口与全屏结果见上方 2026-10-16 记录。

## 桌面操作设置

开关显示“已开启／已关闭”，只表示用户是否允许 Agent 使用桌面操作插件。macOS 另外读取宿主应用的屏幕录制与辅助功能权限；两项均授予后才显示“已授权”。缺少权限显示“还需授权”，仅给出缺失项的系统设置入口；读取失败显示无法确认，不推断为已授权。从系统设置返回及设置面板打开期间重新读取状态。检查不弹授权提示，也不自动改变系统权限。版本号与长说明从主界面移除，失败诊断在“详情”中展开，允许重试或关闭。

使用 Electron 的 [systemPreferences](https://www.electronjs.org/docs/latest/api/system-preferences) 只读接口，`isTrustedAccessibilityClient(false)` 禁止主动提示。开发版显示的是 Electron 宿主的授权，安装包显示对应发行应用的授权；进程实际调用失败仍按既有工具错误反馈，授权状态不保证任意目标应用的操作成功。
