# Industrial Agent Harness 1.0.1-beta.8

## 本版内容

- **修复打包版 GDS 查看器启动失败**：将 `layout.py` 与配色模块解包到真实磁盘目录，外部 Python 使用解包路径启动；保留退出码、信号和有界 stderr，便于定位缺依赖及启动异常。打包首启回归新增发布脚本可读性检查。
- **统一管理 KLayout Python**（#241）：Chip Pack 声明固定的 CPython 3.12.15 与 KLayout 0.30.12，由共享依赖管理器提供“安装查看器支持”和“准备／修复查看器”。仅准备 Viewer 无需宿主 Python 或 Docker；Viewer 就绪与工程工具链就绪分别显示。
- **PCB 官方模型 API 下载支持**：下载器新增固定项目、完整文件路径和提交 SHA 的 GitLab API 通道，配套 PCB 0.3.4 领域包启用。7,252 份 STEP 的路径、大小和 SHA-256 保持原值；打开板图仍只离线计算缺失清单，用户明确下载后才联网，校验成功才写入缓存。
- **远端连接与 macOS 界面修正**：修复 beta.7 对兼容 MCP 1.3.1 服务的连接误判（#244）；隐藏侧栏时，分栏聊天标题避让 macOS 窗口控制按钮（#247）。

## 安装与更新

- 安装包目标为 macOS Apple Silicon（DMG／ZIP）和 Windows x64（EXE）。Intel Mac 与 Linux 桌面安装包不在本版发行范围。
- 请先更新 Desktop，再安装或更新 PCB 0.3.4。其模型目录使用 schema 2，旧 beta.7 会在安装校验时拒绝；仅更新领域目录不能为旧 Desktop 启用新下载通道。
- 在领域包设置中准备或修复 Chip 查看器支持。已有有效 `KLAYOUT_PYTHON` 显式配置仍优先；错误配置会明确报错，不会静默切换解释器。
- 本版仍为内测版本。未配置完整发行证书时，macOS 为 ad-hoc 签名、Windows 无代码签名；签名领域目录继续独立发布，Core OTA 仅在两平台安装包均已签名时更新。

## 验证边界与已知限制

- macOS arm64 候选 `.app` 的包内 RasterService 已完成真实 GDS 到 PNG 验证，包括 Sobel 的 22 个图层。该记录不代表最终发行包的干净构建、完整文件树／缩放／全屏 UI 或 Windows／Linux 原生渲染已通过。详见[打包验证记录](../evidence/layout-packaged-20261021/README.md)。
- PCB API 下载的地址绑定、零网络计划、完整性校验、失败清理及离线缓存已有回归；生产下载器从官方 API 实际取得一份 40,618 字节的 STEP，HTTP 200、SHA-256 与目录匹配，离线重开复用缓存且零新增请求。最终领域包切换后的界面下载仍需验收；该记录不代表全部 7,252 个模型或所有网络均可访问，GitLab API 仍受源站可达性和限流影响。
- 复杂 PCB 的完整 GPU 交互与持续性能验收仍未完成；大 GDS 流式 2.5D（#226）未纳入本版。Viewer 渲染与依赖准备不代表 DRC／LVS、PPA 或工程验收通过。
