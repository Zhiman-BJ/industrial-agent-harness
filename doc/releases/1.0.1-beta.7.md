# Industrial Agent Harness 1.0.1-beta.7

## 本版内容

- **恢复在线领域目录**（#231）：领域目录与 `.hpack` 的签名、校验和发布独立于桌面安装包代码签名。未签名内测包仍不提供 Core 自动更新，领域包可以从签名的 beta 目录获取和更新。
- **远端聊天准备**（#230）：可以先建聊天，再由 Agent 提出文件及工具计划；授权绑定精确范围，同任务内自动同步已批准文件的新内容。新增文件、工具或任务仍需确认。
- **PCB 3D 元件模型**（#235）：读取板图实际引用的 STEP／支持的静态 WRL，保留前后面放置与变换；缺失官方 STEP 可按需下载至校验缓存。打开板图不会自动下载整个模型库，缺失／超限模型明确显示。同步固定的外部 Domain Packs `5cc78f4`，包含 PCB／FreeCAD 本地验证契约修复和官方模型目录。
- **本机 Agent 分层隔离**（#236、#238）：macOS 使用可启动的 Seatbelt，Linux 使用可启动的 bubblewrap；工程、会话和 scratch 可写，受保护目录及敏感凭据路径受限，封堵宿主 Unix socket 路径。隔离原语不可用时回退当前用户权限；Windows 当前仍无本机 OS 隔离。实际边界以会话报告为准，不能把审批或工作目录当成 OS 隔离。
- **验证与当前输入分开**（#239）：历史验证结论绑定记录的输入；工程被原生工具、IDE 或人工改动后，当前输入显示 changed／stale，不继续把旧检查当成当前工程通过。
- **界面与发布验收修正**：简化模型选择控件（#234）；修正 PCB 3D wheel 验收输入、受控模型对环境诊断的误判，以及打包冒烟中旧的 current-user 固定断言，保留真实拒绝、原缩放阈值和平台边界检查。

## 安装与更新

- 安装包目标：macOS Apple Silicon（DMG／ZIP）、Windows x64（EXE）。Intel Mac 与 Linux 桌面安装包不在本版发行范围。
- 当前为内测版本。未配置发行证书时，macOS 为 ad-hoc 签名、Windows 无代码签名，不提供 Core OTA；签名领域目录及包的分发不受此限制。
- 首次启动后选择领域包并完成对应依赖准备。包可下载不等于专业软件已安装或工程能力已验证；部分本地工业 Profile 仍需要 Docker。
- beta.6 与 beta.7 使用同一 beta 领域目录地址。该目录由本次发布流水线实际发布后，旧版 beta.6 也可恢复访问；应用安装包本身仍需手动更新。

## 验证边界与已知限制

- 发布以 `desktop-v1.0.1-beta.7` 标签的工作流和资产为准；源码、安装包首启、真实工业软件与远端任务分别验收。
- PCB 3D 官方模型下载／哈希校验／CPU 解析已有证据；复杂真实板的完整原生 GPU 交互与持续性能验收仍未完成。大 GDS 流式 2.5D（#226）未纳入本版。
- KLayout Python 仍是 GDS／OASIS 本地 Viewer 的前置，尚未统一纳入共享依赖管理器。源码工作树可通过 `pnpm --filter @industrial-agent-harness/desktop setup:layout` 准备。
- 远端 CAD 共享服务链路已用真实 Kimi、真实工具和本地受控模型验收；不将受控模型结果当作生产模型自主规划能力或所有领域的完整桌面验收。
- 输入匹配仅覆盖已记录文件，不保证未声明依赖闭包、跨文件原子快照或完整工程恢复。平台签名、公证、Core OTA 和正式开源发行另行验收。
