# Industrial Agent Harness 1.1.0-beta.9

## 本版内容

- **发版自动化**（#250、#263、#264、#259）：引入 release-please 管理桌面版本——`feat`/`fix` 提交自动累积进常驻 Release PR，合并该 PR 即打 `desktop-v*` 标签、创建 Release 并触发安装包流水线；发版完成/失败自动推送飞书群通知（成功含 mac/win 下载直链）。自本版起版本线为 `1.1.0-beta.N`：feat/fix 只递增 beta 序号，特殊版本用提交 footer `Release-As:` 指定。
- **2.5D 布局流式渲染**（#226）：Viewer 按源数据精度流式输出 2.5D 布局瓦片，资源占用有界。
- **打包版沙箱执行修复**（#255）：修复打包应用在任务沙箱内以 Node 模式启动即崩溃（dyld 阶段退出）的问题。沙箱按真实路径只读放行最近应用安装目录（与项目目录互斥、符号链接不可扩权）；仅为绑定的 Electron 运行时注入 `ELECTRON_RUN_AS_NODE`；外部 Python 网关脚本移出 ASAR 并拒绝调用方覆盖路径；SDK 与桌面的解释器选择修复（大小写后缀、Windows 分隔符、junction 别名）。打包首启冒烟新增真实沙箱任务自检：Node 模式启动、选中输入可读、未选项目输入与沙箱外文件拒绝、输出目录可写。

## 安装与更新

- 安装包目标为 macOS Apple Silicon（DMG／ZIP）和 Windows x64（EXE）：[Release 页面](https://github.com/Zhiman-BJ/industrial-agent-harness/releases/tag/desktop-v1.1.0-beta.9)。
- 本版为未签名内测构建（macOS ad-hoc 签名，首次打开经 系统设置 → 隐私与安全性 → 仍要打开 放行；Windows SmartScreen 需选择“仍要运行”）。无 Core OTA；签名领域目录与 `.hpack` 分发不受限（cad/chip/godot/pcb + `catalog.json` 均已发布到 beta feed）。
