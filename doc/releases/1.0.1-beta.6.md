# Industrial Agent Harness 1.0.1-beta.6

## 本版内容

- **项目创建与领域包引导**（#210）：支持创建通用项目；未安装领域包时提供安装入口，已安装领域包可在项目创建时选择。
- **远程执行接入**（#200）：接入远程沙箱执行、CAD 结果文件展示和会话资源释放。
- **账号绑定与任务收尾**（#189）：远程请求获取令牌后再次校验账号绑定；界面展示异常时仍完成任务状态收尾。
- **桌面界面与开发启动修复**（#220、#217）：合入界面回归修复及模块化验收流程，修复 Windows 开发启动器对子进程的调用。

## 验证范围与发布条件

- 本次版本准备基于 main `9d8e4a533a060b961258a489a43abe6915bb749b`。该提交的 macOS/Windows 桌面打包首启、四个平台 Portable、Linux installed-chip 和两条 macOS vertical-slice 检查已通过。
- **发布阻塞**：macOS 15/26 的 PCB/Godot 完整安装验收尚未通过。CI runner 缺少 Linux Docker engine，两个用例在安装前置检查中报 `Docker was not found`，尚未执行真实工程任务。问题跟踪见 [#219](https://github.com/Zhiman-BJ/industrial-agent-harness/issues/219#issuecomment-6248741254)。需要补齐真实执行环境并完成验收后，再推送版本标签。
- 本版本准备不代表安装包已发布。版本标签必须为 `desktop-v1.0.1-beta.6`，并与 `apps/desktop/package.json` 一致；实际安装包和首启结果以该标签的发布工作流为准。

## 安装范围

- 计划产物：macOS Apple Silicon DMG/ZIP、Windows x64 EXE。
- 现有发布配置生成内测安装包：macOS 使用 ad-hoc 签名，Windows 无代码签名；不提供应用内自动更新。签名、公证和自动更新不能视为已验收能力。

## 已知发布问题（2026-10-20 核查）

- 本版安装包已经发布：[desktop-v1.0.1-beta.6](https://github.com/Zhiman-BJ/industrial-agent-harness/releases/tag/desktop-v1.0.1-beta.6)，对应提交 `8d4bfc792abc8a9314f6b65c1a57348703747435`。上文“发布阻塞／计划产物”为发布准备时的记录，不代表线上资产尚未发布，也不补充未执行的领域验收。
- **应用内更新被明确禁用**：未签名内测包的 `coreUpdateEnabled=false`，Check updates 显示未配置，不会向占位地址请求或下载应用更新。
- **在线领域目录也不可用，这是发布缺陷**：客户端指向 `desktop-beta-feed/catalog.json`，但发布流水线因安装包未签名，在发布共享 feed 前退出。2026-10-20 核查时该 feed 不存在，目录地址返回 HTTP 404；版本发布页下的签名 `catalog.json` 则返回 HTTP 200。
- macOS arm64 可回退到内置的 cad/chip/godot/pcb 四个**可选**领域包；这不等于已经安装、依赖已准备或工程功能已验收。Windows x64 默认不内置这些可选包，因此干净安装时不能把声明的领域卡片视为可安装包。
- 本次发布的签名目录仅把 chip 声明为支持 Windows；cad/pcb/godot 仅声明 macOS arm64。补发目录也不会自动扩大领域的平台支持范围。
- 安装包代码签名与领域目录 Ed25519 签名相互独立。后续修复应恢复签名领域目录及对应 `.hpack` 的发布，同时保留未签名应用不发布 Core OTA 的限制；不应通过关闭目录签名验证或开放未签名应用自动更新来解决。
