Development preview of the headless Industrial Agent Harness. The archive contains the CLI, Capability Broker, repository Skills, Domain MCP registry, and Kimi SDK integration. It does not contain Electron, Kimi CLI, or industrial executables. The current Domain MCP registry has no default servers.

Download the `.tar.gz` asset and its `.sha256` file from this release. Follow the [headless installation instructions](https://github.com/Zhiman-BJ/industrial-agent-harness/blob/main/apps/cli/README.md#github-release-%E5%AE%89%E8%A3%85) for extraction, checksum verification, and the first scenario run.

Scope-only scenarios need Node.js 22 or newer. Agent scenarios also need a separately installed Kimi CLI and a model API key. Industrial action execution and persistent verification are not yet implemented.
