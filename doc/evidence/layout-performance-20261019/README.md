# 版图性能、异常恢复与语言兼容验收

2026-10-19。此次在 macOS 上使用现有 Sobel（22 层）和 OpenLane FIFO（41 层）完成受控后端压力测试及组件生命周期/语言回归。发现的资源释放和多余请求问题已修复；不据此承诺任意版图、长时间运行或所有 GPU 均无崩溃。

## 已修复的实际问题

- 隐藏 2D 仍会发出渲染请求，与 3D 争用 worker。组件计数回归从隐藏期间 3 次新请求变为 0；恢复显示后只请求最终参数。
- 概览 ImageBitmap 创建成功、后续像素读取失败时没有释放图片。异常路径现在关闭图片，回归 close 次数从 0 变为 1。
- WebGL context loss 后仍保留无恢复用途的驻留缓存。现在立即清空缓存和相关资源计数；回归驻留项从 1 变为 0。
- 已收到隐藏/卸载信号后的迟到渲染与解码结果被丢弃并释放，不再通知已隐藏视图就绪。
- 预算拒绝保留已有概览；实际组件回归覆盖 4 层概览、240000 个精细三角形峰值及超额精细请求拒绝。

这些异常与生命周期测试运行实际组件回调，IPC 与图形环境使用测试替身；不等价于真实驱动 context loss 或原生窗口长时间测试。

## 语言兼容

实际偏好为 `system`、`en`、`zh-CN`。系统主要语言为 `zh-*` 时使用简体中文，其他未支持系统语言回退英文；这不是繁体中文或其他语言翻译支持。

- 补齐缺失布局文案、默认图层名和画布无障碍说明，自定义图层名及技术标识保留原值。
- Electron 标准 invoke 错误包装中的已知诊断可以翻译，未知错误保留完整原文。
- 真实组件语言回归验证反复中英切换保留 mode、camera、selection、visibility、ROI、theme 和 spacing；不重建场景，不增加原生请求、取消请求、监听器或资源。卸载后清理完成。
- 测试预览增加实时语言选择和本地化页头/页脚；生产语言范围不变。

最终验证：Viewer 101/101（KLayout 启用、无跳过）、语言 11/11、架构 48/48，Desktop TypeScript/Vite 构建及测试诊断模块 TypeScript 检查通过。此前工具超时导致重复落盘的一条语言测试已删除，不重复计数。

## 实际界面证据与剩余限制

本轮 CUA 短暂恢复后读取到真实 FIFO 中文 2D 页面正常就绪、41 层信息，测试诊断观测到 2D ready 473.6 ms、错误/未处理 rejection 均为 0；这是开发预览的 DOM 就绪观测，不是首帧、FPS 或最终构建视觉验收。随后 3D 操作时控制连接中断，没有取得最终画面截图，不能据此认定产品崩溃或界面验收通过。

原生 Electron、英文实际排版与动态语言切换的原生界面、持续交互帧率和长时间资源趋势仍待验收。当前仍为完整解析输入、768 MiB worker RSS 软保护，尚非外存分页或 OS 硬内存隔离。

可在本地 [FIFO 诊断预览](http://127.0.0.1:43125/?fixture=sync-fifo-real&lang=zh&perf=1) 查看就绪观测、交互窗口 rAF 间隔、长任务及错误计数。该测试面板仅在 `perf=1` 启用，样本数量有界并有卸载清理；rAF 间隔不等于实际渲染 FPS，缓存计费不等于进程/GPU 实测内存。
