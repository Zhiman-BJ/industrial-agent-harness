# Sobel 实时图像滤镜芯片 — 需求规格

项目：sobel-filter（教学 / 自主芯片设计流程演示 Demo）
路线：digital-asic，目标阶段：physical_design（含 GDS 导出与可用的签核证据）
日期：2026-09-15

## 1. 功能需求

| ID | 需求 |
|----|------|
| F1 | 对输入 8 位灰度图像做 3×3 Sobel 边缘检测，流式处理，不缓存整幅图像 |
| F2 | 梯度幅值 = \|Gx\| + \|Gy\|（Gx 为右列减左列加权和，Gy 为下行减上行加权和） |
| F3 | 二值化：幅值 >= 阈值 输出 255，否则输出 0；阈值为 8 位、逐帧可配 |
| F4 | 输出图像尺寸与输入一致；最外围一圈像素固定输出 0 |
| F5 | 图像宽度 3～128，高度 3～65535；尺寸逐帧可配 |
| F6 | 行缓存：仅使用两条行缓存（各 128×8 bit 上限）构建 3×3 滑动窗口 |

## 2. 接口需求

| ID | 需求 |
|----|------|
| I1 | 单时钟 `clk`，同步低有效复位 `rst_n` |
| I2 | 输入 `in_valid`/`in_ready`/`in_pixel[7:0]`，valid/ready 握手 |
| I3 | 输出 `out_valid`/`out_pixel[7:0]`/`out_frame_start`/`out_frame_end`；下游始终可接收 |
| I4 | 允许输出空拍；不得丢失、重复或打乱像素顺序 |
| I5 | 配置端口 `cfg_width[7:0]`、`cfg_height[15:0]`、`cfg_threshold[7:0]`，在每帧第一个被接收的像素处采样锁存 |

## 3. 性能 / 物理目标

| ID | 目标 |
|----|------|
| P1 | 目标时钟 100 MHz（周期 10 ns），行内稳态吞吐 1 像素/周期 |
| P2 | 工艺：Nangate45 / FreePDK45（教学工艺，OpenROAD-flow-scripts 自带平台文件） |
| P3 | 芯片区域 250×250 μm 内完成物理实现 |
| P4 | 面积与功耗以记录评估结果为主，不做额外优化 |

## 4. 验证需求

| ID | 需求 |
|----|------|
| V1 | 使用独立参考模型（Python，与 RTL 分离实现）验证算法与接口行为 |
| V2 | 覆盖最小尺寸 3×3、最大宽度 128、行计数超过 8 位的高度、阈值边界 0 与 255、输入随机空拍、多帧背靠背与逐帧改配 |
| V3 | 逻辑综合（Yosys + Nangate45 liberty）、布线后 STA（OpenROAD/OpenSTA + SPEF）、功耗报告 |
| V4 | GDS 导出（KLayout），DRC（FreePDK45 KLayout 规则）；LVS 视工艺数据完备性如实评估 |

## 5. 明确排除

- 不实际流片、不封装、不做实物测试。
- 不声称代工厂签核（foundry signoff）；教学 PDK 不支持该级别声明。
- 面积/功耗不设优化目标，仅记录实测值。
