# Sobel chip design sample

A small source snapshot from [`Zhiman-BJ/eda-harness-demo`](https://github.com/Zhiman-BJ/eda-harness-demo/tree/main/demos/sobel). The seven source files were extracted from the demo's `artifacts.tar.gz` using paths and SHA-256 hashes in `manifest.json`. This directory is for browsing and trying the Agent workspace; it does not include the PDK, full flow outputs, or a verified runnable EDA environment.

`outputs/` contains one Sobel netlist, waveform and layout from the same recorded design. They were extracted by `demos/sobel/manifest.json` path and SHA-256, solely so the project file tree can exercise the corresponding built-in Viewers. These are recorded outputs, not evidence that this reduced source snapshot can reproduce the full flow.
