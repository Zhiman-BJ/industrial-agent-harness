# PCB LED example

A small two-layer demonstration board with a two-pin input, a 330-ohm resistor and an LED. The schematic embeds its three symbol definitions, and the board embeds its footprints, so no external symbol or footprint libraries are needed for viewing.

Create a project bound to this folder with domain **PCB**, open the workspace and file tree, then select `led.kicad_pcb` for the board or `led.kicad_sch` for the schematic. Pan, zoom, inspect components and toggle board layers in the embedded KiCad Viewer. No KiCad installation or model API is required for this read-only preview.

The files are original KiCad 6-format example sources. `led.kicad_pro` groups the schematic and board for the native KiCad project manager. They demonstrate the viewer; they have not passed ERC, DRC or manufacturing review and are not a production design.
